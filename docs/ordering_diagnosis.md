### 2.2 三个必须同时看的数字

```
穷举最优   -20.83
质心 TSP   -21.32   ← 只差 0.49：这是「排序维度」的实际天花板
```

- **错误集中在起点**：6~7/10 的实例在**第一个地块**就选错。起点决定整个环游走向，

## 三、诊断：已经排除什么、剩下什么

### 3.1 已排除：信息不足 / 表示坍塌

一个自然的怀疑是「网络看不出地块之间的差别」。**用两个实验否定掉了。**

1. **线性探针**（从嵌入线性恢复位置）：

   | 探针 | R² |
   | --- | --- |
   | Field 嵌入 → 地块位置 | **1.000** |
   | Boundary 嵌入 → 边界位置 | **0.993** |

   位置信息**完整保留**。

2. **有效秩低不是缺陷**：Field 输入有效秩 3.1/7、投影后 3.2/20、2-stage 后 2.5/20；
   Boundary 2.4/4 → 2.1/76 → 1.9/76。
   低秩是因为**位置本来就是 2 维**（内在维度低），且投影（线性映射）保秩、
   GAT 只轻微加剧（3.2→2.5）。**不是过平滑。**

3. **关系图确实接近全连接**：20 地块时 `E_BB_inter` = 5476 条边 / 边界两两可能数 5700 =
   **96%**。这会让 Stage 1 的消息传递接近全局平均，但边特征里带距离、attention 会用到，
   因此**没有造成信息损失**（探针已验证）。

### 3.2 已排除：地块 head 看不到边的代价（已修，有增益）

第一次层次化解码的 `field_head([z_F, z_G, remaining])` **一条边信息都没有**，
而 flat 解码器的候选上下文是 `[z_F, z_entry, z_exit, z_G]` —— 拆分时把这条信息弄丢了。
补上「该地块所有可行 (entry, exit) 的最大池化摘要」（`6d030ca`）后：

- τ：−0.06 → **+0.08**
- gap：2.93 → **2.57**
- 首个地块就错：7/10 → **6/10**
- 20 实例配对：−23.75 → **−23.45**（100 轮即超过 flat 的 100 轮 −24.28）

**方向正确、但增益有限**，且带来一个副作用：最近地块率 60% → **77.5%**、
实走/最近 1.19× → **1.07×**，即**更倾向「就近走」**。
原因可解释：进门代价主导地块分数，而进门代价与「离得近」高度相关。

### 3.3 剩下的瓶颈（我的判断）

**信息是齐的，缺的是「决策函数」和「信用分配」。**

1. **决策函数是逐点的**：`score_i = f(context_i)`，候选之间**没有任何交互**，
   唯一共享的是池化的 `z_G`。而排序是**集合级**选择 —— 「A 比 B 好在哪」需要
   把 A、B 放进同一个比较上下文里。现在网络只能靠 4 个手工的「剩余集合标量特征」+
   池化全局向量来间接表达。
2. **信用分配的信噪比太差**：排序收益约 **2 分**，而单局 reward 的波动 sd ≈ **2.6**。
   PPO 的 bandit 反馈（每步只有被选中的动作有回报）无法从这种信噪比里提炼出一个
   **延迟的、全局的**决策。这也解释了为什么「改地块 head 看到什么」的两次尝试
   只带来 ~0.1 的 τ 变化 —— 它们改变的是**决策依据**，不是**比较机制**。

## 四、从网络结构入手的三条路（按推荐顺序）

### 方向 1：候选集合交互（跨候选注意力）—— 首选

- **现状**：打分逐点，候选间无交互。
- **改法**：打分前对候选集做一轮 self-attention（或在「唯一地块」集合上做，
  再把结果广播给该地块的所有 (entry, exit) 变体）。
  每个候选的分数因此成为**所有候选的函数**，可以直接表达「相对比较」。
- **为什么可能有效**：这是集合选择（Pointer Network 之后）的标准结构；
  它正好补上「决策函数无法比较候选」这一条。
- **成本**：合法候选 ≤ ~100，O(C²) 可忽略。**风险低。**
- **预期**：首个地块就错的比例应该最先动（那是纯比较问题）。

### 方向 2：每候选对「剩余集合」的注意力（替换 4 维手工特征）

- **现状**：`remaining_set_features` 是 4 个手工标量（到质心距离、到最远距离、
  剩余比例、剩余集合直径）。
- **改法**：以候选为 query、对**剩余地块集合**做 attention，得到候选条件化的集合表示。
- **为什么可能有效**：起点决策的依据就是「剩余集合的几何 + 我在其中的位置」；
  注意力可以学到比「到质心距离」更复杂的判据（例如**极值点/链端点**），
  而「从端点开始扫」正是 TSP 最优解的结构特征。
- **成本**：C × n ≤ 100 × 20 = 2000。**风险低。**

### 方向 3：把「前瞻」做进结构 —— 学习到的转移代价 + 可微单步 Bellman

- **现状**：地块分数只依赖「我现在离它多远 + 它长什么样」。
- **改法**：学习一个地块间代价 `c_θ(i, j)`（n×n，n ≤ 20），
  地块分数加上 `−γ · softmin_j c_θ(a, j)`（j 遍历剩余地块），
  即「去了 a 之后，下一步最省还要多少」。这是**在网络内部做一步前瞻**，
  不需要外部专家、不需要推断时搜索，`softmin` 可微、PPO 端到端训练。
- **为什么可能有效**：直接给网络一个 TSP 式的表示能力 ——
  「去 A 好，因为 A 之后剩下的都很近」。这是当前完全缺失的项。
- **成本**：n² ≤ 400 个标量。**风险中**：`softmin` 温度需调，
  且退化时可能收敛到「最近邻」（我们已知那是次优的）。

### 方向 4（低成本补充）：把 TSP 专家作为**参照基线**加入评估

不改模型，只在 `policy_paths` 里增加「质心 TSP」一行，让每次评估都能直接看到
「策略 / 最近地块 / 质心 TSP / 穷举最优」四个水平，避免再出现「超过启发式就以为做好了」
这种误判。

## 五、评估协议（已建好，不要改）

任何结构改动都跑同一套，**100 轮即可**（已证明 100–250 轮收敛）：

1. `order_reference`（10 个 5 地块实例）：**首次分歧位置**（最敏感）、**Kendall τ**、
   gap-to-best、beats%、2-opt 闭合率。
2. `probe_policy_metrics`（20 个实例）：配对 greedy vs 未训练、最近地块率、实走/最近。
3. `policy_paths`（5/10/20 固定场景）：策略 vs 启发式的完整路径可视化。

**当前基线（用来对比）**：τ **+0.08**、gap **2.57**、首个地块就错 **6/10**、
20 实例配对 **−23.45**、最近地块率 **77.5%**、实走/最近 **1.07×**。

## 六、一句话总结

> 信息不缺（探针 R²=1.000），训练不缺（100 轮收敛），缺的是
> **能比较候选的决策函数**和**能穿透噪声的信用分配**。
> 两次「改地块 head 看到什么」的尝试合计只把 τ 从 −0.02 推到 +0.08；
> 下一步应该改**比较机制**（方向 1/2）或**引入结构化的前瞻**（方向 3）。
