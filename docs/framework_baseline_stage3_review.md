# 第三段：D→P 实现与验收

基线 197f179；2026-11-11。未运行正式面板、训练或跨方法性能对照。

## 实现

`baseline/divide_then_plan.py::DivideThenPlanGA` 继承既有 NestedGA 的 inner
选择/交叉/变异/精英保留和 fitness；外层改为完整子任务排列。
预处理在 run 开始计时后执行：长轴法向排序、邻接连通分量、面积中位切分，
使用真实指定区域规划器检查满资源从 depot 出发且保留返航资源的可行性。
载荷面积下界不满足时可直接切分，避免重复几何探测。
每个叶区域枚举全部门组合，保存满资源可行门列表；内层 random key 映射到这个固定列表。
当前资源不足则通过第二段共享接口补给，不能重分区或调用 CC fallback。

分区通过 validate_partition 后冻结为 RegionTask 元组。外层使用排列保持的前缀交叉，
再交换或插入；门 key 跟随任务。初始化为子区域质心最近顺序与最近入口规则，
不是原始 NN，不使用 RL。单点不可行、分区超过 max_steps 都报告失败，不丢任务。

## 预算、失败与记录

- 分区、可行门枚举、初始化和所有候选执行均计入墙钟；独立重放单列。
- 预处理探测单独记录，不冒充完整候选评估；完整候选失败/中断也占评估次数。
- 时限在几何探测和任务执行边界检查，单次几何调用不可抢占，故墙钟是软上限。
- 分区或初始化未找到完整解可返回 best=null；CLI 不把它当成功或免费补全。
- 记录每个分区探测的点 ID、门列表、拒绝原因；候选顺序、key、quota 和 incumbent。
- 门预检的 ValueError 记录为该门不可行；其他异常传播。候选执行中仅资源不足计失败，
  几何/程序/账本错误传播，避免吞掉实现缺陷。第五段须审查预处理拒绝原因分布。
- 一个 inner 的最后候选被 wall-limit 中断时，该 quota 标记 partial，不进入外层繁殖。

## 验收

新增 test_divide_then_plan.py 五项：
1. 真实小矩形受载荷限制产生多个固定区域；精确无遗漏分区、连通性、9 次评估两轮外层、重放与同 seed 确定性。
2. 单点不可行明确 partition_failure，无伪造完整 incumbent。
3. 分区期间耗尽墙钟，无免费预处理或候选执行。
4. 不完整排列被拒绝，不触发 fallback。
5. 注入 RuntimeError 传播，不当作普通低适应度。

相关套件（D→P、framework contracts/execution、nested GA、controls）：50 passed。
