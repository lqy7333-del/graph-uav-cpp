## 分段交接约定

每段提交：SHA、实际测试、未完成项、下一段入口、算法/物理/预算是否改变。
计划与协议是持续交接依据；任何语义变更须写入版本记录，不静默替换。
不得因测试通过就把尚未实现的完整框架标为完成。
本轮不改 RL，不启动训练，不自动开展正式搜索。
既有根工作区及其他 worktree 保留，不在其中混入本分支代码。
