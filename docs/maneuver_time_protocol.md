# 机动时间改造 · 实验协议（已冻结）

代码基线：`codex/maneuver-time`；本协议与本目录下的测试、配置一并提交后生效。
训练一旦启动 **代码冻结**；发现 bug 则停止受影响实验并标记无效，不边改边混统计。

## 1. 应用范围（冻结 ✓）

| 项 | 值 |
|---|---|
| 地块数 | **5–20 全部整数** ✓（实测 160 次 reset 全覆盖，每规模 7–17 次 ✓）|
| 单块面积 | **0.5–2.0 ha** ✓（以 `default.yaml` 实际生成为准 ✓）|
| 面积与块数的关系 | **独立** ✓（实测 5/10/20 块均值 1.28/1.21/1.14 ha ✓）|
| depot 位置 | 沿用现有生成规则 |
| 5 块补给次数 | 实测 **3 次** ✓ |

## 2. 无人机控制情景（冻结 ✓）

| 项 | 值 | 说明 |
|---|---|---|
| `ppo.randomize_uav` | **false** ✓ | 本轮固定控制情景 ✓ |
| `uav.speed` | **8.0 m/s** ✓ | 与 `rl.time.cruise_speed` **一致** ✓ |
| `uav.coverage_width` | **10.0 m** ✓ | 与 `rl.reward.coverage_width` **一致** ✓ |
| `uav.alpha` / `beta` | 0.08 / 0.02 ✓ | 能耗 = `alpha·d + beta·A` ✓ |

**一致性断言**：`CoverageEnvironment.__init__` 在 UAV 能力与时间/抵扣参数不一致时**直接报错** ✓，
不再是静默不一致 ✗。

## 3. 机动时间代理（冻结 ✓，规划成本代理，非动力学模型 ✗）

```
Δt_turn(θ) = τ_π · (|θ|/π)^p        τ_π = 3.0 s, p = 2.0
```

- 仅依赖**方向** ✓ ⇒ 重复点 / 共线细分 / 转角拆分 / 直线拆分 均不改变成本 ✓（实测 0.0 ✓）
- `τ_π = 3.0 s` 为**仿真参考情景** ✓，**不是**已标定的掉头时间 ✗
- **不声明**满足真实加减速/过弯速度约束 ✗

## 4. 时间账本（冻结 ✓）

```
T_total = T_work_base + T_nonwork_base + T_maneuver_extra + T_service
```
- **所有飞行段（含补给返航与最终返航）统一经 `path_time` 结算** ✓，
  到达停机后才清除方向 ✓ ⇒ 飞向 depot 前的转弯**计入** ✓
- `time_service` 只挂在**补给服务事件**上 ✓，不在每个 Configuration 上收 ✗
- `summary` 暴露 `total_time` 与四项 ✓，并显式给出 **`time_closure_error`** ✓
- 指标名称：**「模型估计的飞行时间，含机动损耗，不含补给服务及起降耗时」** ✓

## 5. Reward（冻结 ✓）

```
rl.reward.mode = distance | time
time 模式: r_t = -(ΔT_t - ΔA_unique,t/(coverage_width·nominal_work_speed)) / T_scale
```
- 只抵扣**本步新覆盖面积** ✓，重复覆盖抵扣 **0** ✓
- `T_scale = 100` 全局固定 ✓，不按实例面积/块数/参考策略归一化 ✓
- `distance` 模式**完整保留** ✓（A 组用它 ✓）
- `gamma = 1.0` ✓

## 6. 评估规则（冻结 ✓）

### 6.1 checkpoint 选择
1. 首先按固定验证集成功完成的实例数排序，完成更多者优先。
2. 只有全部验证实例完成的候选，才按完整固定集的规模等权平均 `total_time` 选择。
3. 若无候选全部完成，报告可靠性门槛未通过；相同完成数按预先固定的较早 update 打破平局，不比较不同成功子集的均值。失败数量及原因始终报告。
4. 每 20 updates 存一次 ✓

## 8. 结论边界

允许：「固定控制情景 + 0.5–2.0 ha 范围下，统一模型在 5–20 地块新实例上的表现」
不允许：任意农田适用 ✗、跨机型泛化 ✗、仿真机动成本 = 实测时间 ✗、每个实例都优于 NN ✗
