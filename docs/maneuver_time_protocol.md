## 7. 训练设计（锁定）

### 7.1 A/B 定义
| 组 | reward | 其它 |
|---|---|---|
| **A** | `distance`（原目标，`-d/total_area*scale`）| 完全相同 |
| **B** | `time`（`-(T - A_unique/(w·v))/T_scale`）| 完全相同 |
| **NN** | 冻结启发式，同一执行模型 | — |

A/B 差异**只有 reward 模式** ✓；同网络、同输入（16 维 UAV 特征 ✓）、同混合规模分布 ✓、同预算 ✓。

### 7.2 规模与实例
- 训练分布：`num_fields ~ U{5..20}` ✓（实测 160 次 reset 全覆盖 ✓，每规模 7–17 次 ✓）
- 单块面积 0.5–2.5 ha ✓，与块数无关 ✓
- **旧 checkpoint 不兼容**（13→16 维 ✗）⇒ A/B **从随机初始化** ✓

### 7.5 checkpoint 选择规则（训练前锁定）
1. 必须先满足：完成率 ≥ 验证集的 95% ✓
2. 再按**规模等权**的平均验证时间最小 ✓
3. 同时报告逐规模结果 ✓，若某规模显著退化须在报告中说明 ✓
4. 每 20 updates 存一次 ✓，只保留最优 + 最后 3 个 ✓
